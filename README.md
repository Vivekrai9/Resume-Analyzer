# Resume Analyzer

Resume Analyzer is a full-stack web application that helps users analyze resumes and prepare for interviews using AI-powered features.

# Features
User registration and login
Authentication and protected routes
Resume analysis
AI-powered interview functionality
Interview reports
User management
Backend API integration
Responsive frontend interface

# Technologies Used
Frontend
React
Vite
JavaScript
SCSS
React Router
Backend
Node.js
Express.js
MongoDB
Mongoose
JWT Authentication
